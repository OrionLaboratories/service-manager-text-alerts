Request one Client Services test alert

Orion Laboratories employees participating in the Service Manager pilot can ask for one automated text about a synthetic Client Services case. The alert contains a case number, a short action and a link that requires Salesforce sign-in.

How to request the test

Use your signed-in private Orion work conversation with the release operator. Ask for one Client Services test text and provide your own mobile number privately if you haven’t already supplied it. You may also ask for the Salesforce bell and work email for the same test.

For example, you can write “Send me one synthetic Client Services alert by text to the mobile number I provided.”

Participation is optional. Each direct request authorizes one alert text. It does not subscribe you to recurring alerts. Message and data rates may apply. Reply STOP to opt out or HELP for help. You can also reach help@orion.healthcare.

This page is for instructions only. Keep your number and the test request in your private Orion conversation.
